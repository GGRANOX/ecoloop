A* search

f(n) = g(n) + h(n)

g(n) — real cost from the start (1 per move).
h(n) — Manhattan distance |Δx| + |Δy| to the bin. It never overestimates, so the path is optimal.

The open list holds discovered cells sorted by f; the cell with the lowest f is expanded and moved to the closed list.

Bayes' theorem

P(C|E) = P(E|C) · P(C) / P(E)
P(E) = Σ P(E|Cᵢ) · P(Cᵢ)

C — true material, E — the evidence (what the classifier saw). The prior is our belief before looking at the photo; the likelihood says how probable this evidence is for each material.
